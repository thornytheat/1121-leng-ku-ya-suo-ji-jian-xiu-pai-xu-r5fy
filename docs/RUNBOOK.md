# 冷库机务值班操作

交班时先打开待检修设备，记下页尾运行指纹。需要调整处置量时，在工作台输入已确认的检修工位（个），查看变更后的待检修设备，再从「下发前复核」核对相关环节。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及六个环节的证据，便于按运行指纹对照。

交班分诊在页面底部「故障分诊交班」。先看每台机组的「去向」和「未决原因」：主责机组直接派对应工种，联合复核需压力、振动两边到场，转下一班要在交接时注明待复查通道。演练保存故障可点「模拟保存失败」，此时只有失败前的分诊单确认落账；排除故障后点「从已确认分诊处恢复」，或多次「重跑」，同一机组同一班次始终只有一张分诊单。接口为 `GET/POST /api/triage/*`，样例见 `sample_data/fault_triage_cases.json`。
